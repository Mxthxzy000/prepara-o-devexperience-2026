# Ferramentas de Desenvolvimento do projeto:
O projeto foi desenvolvido utilizando ferramentas básicas de desenvolvimento como php, css e estrutura em html, com um banco de dados local utilizando o xampp.

# Como rodar o site
Primeiro faça o download do arquivo "arquivo_banco.sql" e da pasta contendo o código fonte do site "HELPDESK_INDUSTRIAL", pegue a pasta e coloque-a dentro da pasta htdocs do xampp, após isso abra o XAMPP e inicie o Apache e o Mysql, abra no seu navegador a página "localhost/phpmyadmin/" e vá clique na opção escrita "importação" lá você deverá colocar o arquivo "arquivo_banco.sql", abra no seu navegador a página "localhost/phpmyadmin/HELPDESK_INDUSTRIAL/pages/homePage" e aproveite sua aplicação.
