# Ferramentas de Desenvolvimento do projeto:
O projeto foi desenvolvido utilizando ferramentas básicas de desenvolvimento como php, css e estrutura em html, com um banco de dados local utilizando o xampp.

# Como rodar o site
Primeiro faça o download do arquivo "banco.sql" e da pasta contendo o código fonte do site "HELPDESK_INDUSTRIAL", pegue a pasta e coloque-a dentro da pasta htdocs do xampp, após isso abra o XAMPP e inicie o Apache e o Mysql, abra no seu navegador a página "localhost/phpmyadmin/" e vá e crie um novo banco de dados com o nome "helpdesk_industrial" clique na opção escrita "importação" e lá você deverá colocar o arquivo "banco.sql" depois abra no seu navegador a página "localhost/phpmyadmin/HELPDESK_INDUSTRIAL/pages/homePage" e aproveite sua aplicação.


# Funcionalidades
A ferramenta é educacional e foi criada com foco único para a competição DevExperience 2026, porém já possui funcionalidades como:

- Criar novos chamados e cadastrar eles no banco
- Visualizar, editar e remover chamados da lista
- Pesquisar chamados pelo filtro ou pelo nome deles
- Navegar entre as páginas e Utilizar a plataforma
